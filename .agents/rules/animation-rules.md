ANIMATION RULES

Motion should feel intentional.

Do NOT animate everything.

Animate only:

User focus
User actions
State changes
Scroll reveals
Navigation transitions

Use:

Framer Motion
GSAP
Motion One

Animation timing:

Micro-interaction: 150–250ms
Hover: 200ms
Modal: 250–350ms
Page transition: 400–700ms

Animations should feel like Apple-level quality.
